# 连接 PostgreSQL 工作区

双击 `LaoQinProgressManager.exe` 打开桌面软件。默认使用本地工作区，切换到云端时由桌面端直接连接 PostgreSQL。

1. 在 PostgreSQL 中准备名为 `laoqin` 的数据库，并确保使用软件的电脑可以连接它。在左下角点击“登录云端工作区”。
2. 填写数据库地址、端口（默认 `5432`）、数据库账号和数据库密码。设置使用当前 Windows 账号加密保存到本机。远程连接默认验证 PostgreSQL 的 TLS 证书。若服务器在可信内网且未启用 TLS，可勾选“允许非加密连接”。
3. 首次使用时点击“初始化并保存”，核对弹窗中的服务器、数据库和表名。也可下载[初始化 SQL](../src/schema.sql)，由数据库管理员在 `laoqin` 中执行。运行账号需要应用表的查询和写入权限。遇到归属不明的同名表时，程序会停止初始化。
4. 用 `admin` 和初始密码 `123456` 直接登录。需要时可在工作区卡片中修改管理员密码，同一个数据库的各台电脑使用同一密码。员工名单继续用于分配任务和排期。
5. 展开左下角云端工作区，可选“迁移本机数据到云端”或“用云端数据覆盖本机”。两项都是整库覆盖，确认后先把目标端当前数据导出为 JSON，再提交覆盖。完整导入和导出沿用现有 JSON 格式，包含项目、人员、任务、排期、时间线和导出偏好。

点击“刷新云端数据”读取其他电脑的改动。普通保存只写修改过的记录，编辑不同任务可以分别保存。同一条记录已被更新或工作区已被整库覆盖时，旧页面需要刷新才能保存。修改管理员密码后，其他电脑需要重新登录。

从旧版大 JSON 升级时，先退出所有旧版客户端，再在新版点击“初始化并保存”。新版会迁移已确认归属的工作区并保留旧表，其他电脑也需要使用新版。仅执行 SQL 会创建新表，旧数据迁移由新版客户端完成。若以前用了其他库名或旧表没有归属标记，请先用旧版导出 JSON，再在符合条件的 `laoqin` 库中初始化并导入。
