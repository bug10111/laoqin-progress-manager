# 交互式甘特图与任务导出升级

整理范围：2026-10-28～2026-10-31，近三天的提交及本次更新。以下内容可直接用于本次 GitHub Release，版本号由发布标签确定。

## 甘特图排期

- 支持直接拖动：左端调整开始日期、右端调整结束日期、中间整体前移或后移，保留原天数。
- 新增 Shift + 单击多选，整组任务可一起移动，保留各自天数和相对间隔；松开统一保存，每项任务分别记录时间线。
- 拖动显示日期草稿，按自然日吸附，最短一天；支持 Esc 取消、边缘自动横向滚动及失去鼠标捕获取消。
- 新增 Shift + 滚轮缩放，范围 25%～400%，以鼠标所指日期为中心，提供缩放、重置和横向滚动条。
- 顶部日期栏与左侧人员列固定，同组人员姓名吸顶，进入下一组切换，滚动与缩放后日期和任务保持对齐。
- 同一人的任务按完整计划天数从短到长排列，预览与导出一致。
- 任务标识统一放在条后，优先级在名称前；详情说明采用等宽列，编号纵向对齐。
- 优化状态配色、边框和周末背景，提升一天短任务的辨识度。
- 排期窗口可直接修改状态、优先级、负责人和日期，多选任务统一应用，保留原任务及历史。
- 修复状态选择出现两个控件：现在单选、多选、全选共用一个下拉。

## 任务与日期

- 新增 P0～P3 优先级与“测试中”状态；正常流程统一为待讨论、待执行、执行中、测试中、已完成，暂停和关闭单独呈现。
- 列表优先显示执行中、测试中，再按优先级、创建时间倒序排列。
- 状态与优先级可多选，并与名称、备注搜索共同生效；编辑后保留列表位置。
- 原“详情”文案统一为“备注”，已有备注可直接编辑；追加需求独立记录时间，进入同一时间线。
- 列表显示“有备注 / 无备注”和实际节点数，追加后及时更新。
- 日期范围改用双月日历，支持联动、跨月、反向选择及快捷范围。
- 新建、编辑和排期窗口均可清空日期，保留任务状态及原计划历史，暂时退出排期。

## 导出

- 新增任务 Excel：沿用当前项目、状态、优先级和关键词，导出全部匹配任务，包含所有分页。
- 导出前勾选字段、拖动表头排序，成功导出后记住设置，取消不生成文件。
- 追加需求逐条占行，同一任务基础字段纵向合并，长文本完整保留；优化字体、行高、交替底色及报告头，Excel 表头不冻结。
- 详情与 Excel 用连线圆点显示功能进度，当前阶段高亮，暂停与关闭独立标注。
- PDF 直接保留当前甘特图布局，生成单个文件、单张连续页面，完整容纳日期和任务。
- PNG 直接保留当前甘特图布局，生成单张高清图片，默认 3 倍无损分辨率。
- 沿用当前日期范围、状态筛选、分组、任务顺序、缩放列宽和详情，不拆页或打包 ZIP。
- 甘特预览、PDF 和 PNG 共用详情开关及状态筛选，图下编号说明包含完整名称。
