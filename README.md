# 老秦进度管理软件

面向 Windows 的离线项目、任务与人员排期工具。支持直接拖动甘特条调整时间、多人多任务一起移动，以及按筛选条件导出 Excel、PDF 和高清图片。

**无需登录 · 无需服务器 · 本机保存 · C# / WPF · Apache-2.0**

[使用手册](docs/USER_GUIDE.md) · [构建与验证](docs/DEVELOPMENT.md) · [更新记录](CHANGELOG.md) · [本次版本发布说明](docs/RELEASE_NOTES.md) · [发行页面](https://github.com/bug10111/laoqin-progress-manager/releases)

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 项目与人员 | 切换、新增和删除项目、管理共享人员；允许空白工作区 |
| 任务列表 | P0～P3 优先级、七种状态、多选筛选、名称与备注搜索、分页 |
| 备注与时间线 | 直接修改备注，逐次追加需求，记录状态及排期变化 |
| 交互式甘特图 | 拖动两端修改起止日期，拖动中间整体移动，松开自动保存 |
| 多任务移动 | Shift + 单击多选，整组保持各自天数和相对间隔一起移动 |
| 冻结与缩放 | 顶部日期、左侧人员列固定，当前人员姓名吸顶，Shift + 滚轮缩放 |
| 排期编辑 | 多选任务，统一调整状态、优先级、负责人和日期，也可清空时间 |
| Excel 导出 | 按筛选导出全部匹配任务，勾选字段、拖动表头排序、需求逐行展开 |
| 甘特图导出 | 按当前视图导出单页 PDF、完整高清 PNG，或项目 XML |
| 备份与迁移 | 自动保存、上一份数据备份、完整 JSON 导入导出及损坏恢复 |

## 快速开始

1. 获取发行包并解压，双击 `LaoQinProgressManager.exe`；也可按下文构建当前源码。
2. 首次启动附带示例项目。通过左侧项目下拉新建自己的项目，再添加负责人。
3. 新建任务，填写名称、优先级、状态及备注。执行中的任务需要负责人，计划日期可以暂时留空。
4. 点击“安排现有任务”设置排期，或编辑已有任务的完整起止日期。甘特图默认显示“执行中”。
5. 在甘特图上拖动调整时间，或从任务列表、甘特图右上角导出文件。

面向 Windows 10 / Windows 11，目标框架为 .NET Framework 4.6，使用 WPF。已在 Windows 10 Pro 22H2 / .NET Framework 4.8 环境验证；Windows 11 尚未独立实机验证。程序不包含网络请求、遥测或在线更新，尚未签署商业代码签名证书。

## 甘特图操作

| 操作 | 效果 |
| --- | --- |
| 单击任务条或名称 | 打开排期编辑窗口 |
| 拖左边缘 / 右边缘 | 分别修改开始日期 / 结束日期，最短一天 |
| 拖任务条中间 | 整体前移或后移，保留原天数 |
| `Shift + 单击` | 逐项选中或取消；拖任一选中条中间可批量移动 |
| `Esc` | 拖动中取消；未拖动时清空多选 |
| 普通滚轮 / 底部滚动条 | 上下查看任务 / 左右查看日期 |
| `Shift + 滚轮` | 缩放时间轴，范围 25%～400%；也可使用缩放和重置按钮 |

日期包含结束当天。拖动期间只预览，松开后统一保存，并分别记录原计划、新计划和操作时间；状态、负责人及优先级保持不变。多选后拖边缘只调整当前任务。

按人员分组时，同一人的任务按**完整计划天数从短到长**排列。顶部日期与左侧人员列固定，向下查看同组任务时姓名持续显示，进入下一组再切换。单选、多选、全选共用一个状态下拉。

![多选任务一起移动](docs/images/gantt-multidrag.png)

任务标识统一放在条后，顺序为“编号（开启详情时）→ 优先级 → 名称”。“是否显示详情”控制编号和图下完整名称说明；说明采用等宽列，编号纵向对齐。预览可横向滚动查看右侧完整名称。

## 任务、状态与筛选

正常流程：**待讨论 → 待执行 → 执行中 → 测试中 → 已完成**；“已暂停、已关闭”作为特殊状态。任务详情与 Excel 用连线圆点显示流程：已走过的实心、当前高亮、未到达的空心。

列表依次按状态（执行中、测试中、待执行、待讨论、已暂停、已完成、已关闭）、优先级（P0～P3）、创建时间倒序排列。状态与优先级可多选，并与名称、备注搜索共同生效；每页 20 项。

![任务列表与筛选](docs/images/tasks.png)

备注可直接编辑，追加需求独立记录时间。新建、编辑与甘特图排期共用双月日期选择器，均可清空日期：保存后退出当前排期、保留所选状态，原计划写入时间线。

## 导出与备份

| 格式 | 范围与用途 |
| --- | --- |
| XLSX | 当前项目、状态、优先级、关键词匹配的全部任务，包含所有分页；无筛选则导出当前项目全部任务 |
| PDF | 单个文件、单张连续页面，保留当前甘特图布局，页面随完整图表延展 |
| PNG | 单张完整高清图片，默认 3 倍无损分辨率，保留当前甘特图布局 |
| XML | 当前项目完整任务、人员、排期与时间线，不受甘特图状态筛选影响 |
| JSON | 全部项目完整备份与跨电脑迁移，用于“数据导入导出” |

Excel 导出前可勾选字段、拖动调整表头顺序，成功导出后记住设置。追加需求按时间逐行展示，同一任务的基础字段纵向合并；报告头、表头随页面滚动。取消弹窗或保存窗口不会生成文件。

![Excel 字段选择与排序](docs/images/excel-columns.png)

PDF、PNG 直接沿用当前甘特图的日期范围、状态筛选、分组、任务顺序、缩放列宽和详情设置，包含滚动区域内的完整图表。两种格式均只生成一个文件，不拆页或打包 ZIP。大图会适当降低像素密度，保持布局；若原始尺寸仍超过单边 16000 像素或总计 6000 万像素，提示缩小视图后重试。PDF 使用无损高清图像保留中文，不提供文字搜索与复制。XML 是通用格式，并非 Microsoft Project 专用格式。

### 本地数据

默认目录为 `%LOCALAPPDATA%\LaoQinProgress`，可从“数据导入导出”打开。

| 文件 | 作用 |
| --- | --- |
| `data.json` | 当前全部数据 |
| `data.json.bak` | 上一次成功保存的数据 |
| `backups/` | 完整导入前生成的独立备份 |
| `damaged-*.json` | 恢复时保留的损坏文件 |
| `workspace.lock` | 防止多个实例同时写入同一目录 |

数据通过临时文件和原子替换保存。导入完整 JSON 会覆盖当前数据，并先保存独立备份；删除项目会清理其任务、排期和时间线，但保留共享人员与独立备份。自动备份只保留上一份数据，长期备份请手动导出完整 JSON。数据保存在本机且未加密。

## 从源码构建

在 Windows PowerShell 中进入仓库执行，无需下载 NuGet 包或安装 .NET SDK：

```powershell
.\build.ps1
.\dist\LaoQinProgressManager.exe
```

脚本使用 Windows Framework 目录中的 C# 编译器，输出 `dist/LaoQinProgressManager.exe`；可通过 `-OutputPath` 指定目录。程序集版本号为 `1.1.4.0`，发布标签和发行包以对应 Release 为准。

构建参数、独立数据目录、自检命令和源码结构见[开发文档](docs/DEVELOPMENT.md)。检查覆盖持久化、单条与批量拖动、筛选、日期联动、冻结栏、缩放及导出。
