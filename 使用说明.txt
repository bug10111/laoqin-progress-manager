老秦进度管理软件 1.1.0 —— 离线项目管理与人员甘特图

一、启动与运行环境
双击“老秦进度管理软件.exe”即可使用，无需安装、登录或联网，也无需安装浏览器、Python、Node.js 等开发环境。
面向 Windows 10 / Windows 11，使用系统内置的 .NET Framework 4.x 与 WPF。程序为 AnyCPU，可运行于常规 x86 / x64 Windows。
程序以普通用户权限运行，不需要管理员权限，不包含网络请求、遥测或在线更新。
本版本尚未签署商业代码签名证书。

二、项目、人员与任务
1. 左侧项目下拉可以切换项目；下拉底部新增项目，每行右侧的“×”可删除项目。
2. 人员下拉同样支持新增和删除。删除已关联人员时，历史和原任务的人员记录保留，并标注“已删除”。
3. 首次启动自带一个示例项目及示例人员、任务。可以先创建自己的项目，也可以直接删除示例项目；允许一个项目都没有。
4. “新建任务”输入任务名称，选择状态，填写说明。每个任务都归属于当前项目。
5. 将状态设为“执行中”时，必须选择负责人、开始日期和结束日期；随后自动加入甘特图。
6. 任务列表点击名称查看详情与时间线，点击状态进入编辑。时间线记录创建、状态变更、任务修改、排期调整与退出排期的时间。
7. 状态包括：待讨论、待执行、执行中、已完成、已暂停。

删除项目时会清除该项目的所有任务、排期与时间线。可以删除最后一个项目，重启后保持空状态。全局共享人员档案和独立备份会保留。

三、甘特图与多选替换
1. 甘特图默认筛选“执行中”。顶部状态下拉支持多选；底部可选择按人员或按任务展示，以及 7 / 14 / 28 / 31 天视图。
2. 日期按自然日计算，包含结束当天；周六和周日以浅色背景和星期文字标注。
3. 点击某个甘特条，打开排期编辑窗口。先在状态下拉中多选筛选，再从现有任务下拉中多选任务；任务名称在此处通过选择已有任务确定，无需输入。
4. 选择负责人及时间范围，点击“保存并同步甘特图”。选中的任务会使用同一个负责人和起止日期。
5. 选中的任务替换当前甘特条。原任务如未再次选中，退出本次排期，但任务本身、原有日期和历史记录保留。
6. 一个任务在当前甘特图中最多对应一条排期；选择已经排期的任务时，会更新它原有的排期，不会产生重复条目。
7. 替换排期不会自动改变任务状态；保存后会将相关状态加入甘特图筛选，方便立即查看结果。
8. “安排现有任务”可以重新将已退出排期的任务加入甘特图。
9. 更改筛选条件时，任务多选中不再符合筛选的项目会被取消选择。

四、导出
PDF：A4 横向，按日期和任务数自动分页；中文以高分辨率图形保留，适合打印和分享。PDF 中的文字不提供文本搜索或复制。
PNG：输出清晰的图片；多页时自动生成 ZIP 图片压缩包，解压后逐页查看。
XML：导出当前项目的全部任务、人员、排期、是否纳入甘特图及完整时间线。此为通用 XML 数据格式，并非 Microsoft Project 专用 XML。
PDF 与 PNG 沿用甘特图当前的状态筛选，可选择全部排期日期或当前视图的日期范围。
超过 300 页或十年跨度的导出会提示缩小范围，以避免生成过大文件。

五、全部数据导入导出与本地备份
正常启动的数据目录：%LOCALAPPDATA%\LaoQinProgress
可从“数据导入导出”打开数据文件夹。
data.json：全部项目、人员、任务、排期和时间线。
data.json.bak：上一次成功保存的数据备份。
所有修改立即保存，使用临时文件与原子替换减少意外中断造成的数据损坏。同一数据目录只允许一个程序实例写入。
如果主数据损坏或缺失，且备份有效，会自动恢复；损坏文件会另存保留。
“导出全部数据”生成全部数据的 JSON 文件，可复制到其他电脑，在“导入全部数据”中导入。
导入会覆盖当前全部数据；导入前会把当前数据另存至数据目录中的 backups 文件夹。
删除项目或任务需要确认，会删除其任务和时间线；建议删除前先手动备份。自动备份只保留上一次保存，不替代长期备份。
数据未加密，请按实际需要保管电脑和备份文件。

旧版数据兼容：首次启动时如发现旧版 Xucheng 目录中的数据，会自动迁移到新的 LaoQinProgress 目录，旧数据文件保留。

六、快捷键
Ctrl+N：新建任务；没有项目时先新建项目。
Ctrl+E：导出。
